# World Bank WDI Capstone Project

## 📊 Project Overview

This project is the final capstone project for the **AnalystLab Africa Data Analytics Internship – Week 8**.

The project uses the **World Bank World Development Indicators (WDI)** dataset to analyze selected health, economic, and sanitation indicators across countries for the period **2021–2023**.

The aim is to identify patterns and relationships between economic conditions and population health outcomes and present the findings through an interactive **Power BI dashboard**.

## 🎯 Objectives

The main objectives of this project were to:

* Clean and prepare World Bank WDI data for analysis.
* Assess the availability and coverage of selected indicators.
* Analyze health and economic conditions across countries.
* Compare indicators across the years 2021, 2022, and 2023.
* Identify relationships and patterns between economic and health indicators.
* Create visualizations to communicate key findings.
* Develop an interactive Power BI dashboard for data exploration.

## 📌 Indicators Analyzed

The final analysis focused on five indicators:

1. **Life expectancy at birth, total (years)**
2. **Mortality rate, infant (per 1,000 live births)**
3. **GDP per capita (constant 2015 US$)**
4. **Current health expenditure (% of GDP)**
5. **People using at least basic sanitation services (% of population)**

The **Physicians (per 1,000 people)** indicator was initially considered but excluded because of substantially lower and inconsistent data coverage, particularly for 2023.

## 🗓️ Time Period

The analysis focuses on:

* 2021
* 2022
* 2023

These years were selected because they provided more consistent coverage across the selected indicators.

## 🔄 Project Workflow

### 1. Data Collection

World Bank World Development Indicators data was obtained and prepared for analysis.

### 2. Data Cleaning

The dataset was examined for:

* Missing values
* Data types
* Duplicate records
* Indicator coverage
* Country and year consistency

The data was filtered to retain the selected indicators and the 2021–2023 analysis period.

### 3. Exploratory Data Analysis

Exploratory analysis was performed using Python to understand:

* Indicator distributions
* Data availability
* Trends over time
* Differences between countries
* Relationships between health and economic indicators

### 4. Data Visualization

Charts were created to communicate important patterns and relationships within the dataset.

### 5. Power BI Dashboard

The cleaned dataset was imported into Power BI to create an interactive dashboard containing:

* KPI cards
* Year slicer
* Country/indicator filtering
* Life expectancy trend visualization
* Indicator comparisons
* Scatter plot analysis
* Additional visualizations for health and economic indicators

The dashboard allows users to interactively explore how selected indicators vary across countries and years.

## 📈 Key Areas of Analysis

The project investigates questions such as:

* How does life expectancy change over time?
* How does infant mortality vary between countries?
* What differences exist in GDP per capita across countries?
* How much do countries spend on health as a percentage of GDP?
* What is the level of access to basic sanitation?
* Are economic indicators associated with health outcomes?

The final Power BI dashboard provides an interactive summary of the analysis.

## 💡 Key Takeaways

The project demonstrates how publicly available development data can be transformed into meaningful analytical insights.

The analysis highlights the importance of:

* Data quality and completeness checks
* Appropriate indicator selection
* Handling missing data
* Exploratory data analysis
* Effective data visualization
* Interactive dashboard design
* Communicating analytical findings clearly

## ⚠️ Limitations

* Some indicators have missing values for certain countries and years.
* Data coverage varies between indicators.
* The analysis covers only 2021–2023.
* Relationships observed in the data should not automatically be interpreted as causal relationships.

## 🚀 Conclusion

This capstone demonstrates an end-to-end data analytics workflow, from **data collection and cleaning to exploratory analysis, visualization, and interactive dashboard development**.

The project combines Python-based analysis with Power BI reporting to provide a clearer understanding of selected health, economic, and sanitation indicators across countries.
